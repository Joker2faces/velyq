# VELYQ Public Beta Pricing Decision

The owner authorized an introductory configuration for the public beta:

- PRO: €19/month
- ELITE: €49/month

These are implementation defaults, not market-validated claims. Stripe Price
IDs remain environment-controlled and paid checkout stays unavailable until
the corresponding Stripe Test Mode configuration exists. Live charging is
disabled on the Vercel Hobby deployment while commercial-use compliance is
unresolved.
